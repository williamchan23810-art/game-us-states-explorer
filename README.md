# 🎮 game-us-states-explorer

> An interactive web-based educational game designed to help players explore and learn about US states, capitals, and geography through dynamic quizzes and map visualizer elements.

## 🚀 Live Demo
[👉 Click here to play the game live on Netlify!](https://game-us-states-explorer.netlify.app)

---

## ✨ Core Features
* Interactive map visualization and state highlighting.
* Dynamic trivia/geography quiz loop tracking capitals or state shapes.
* Responsive layouts tailored for both desktop and mobile screens.

## 🛠️ Built With
* HTML5
* CSS3
* Vanilla JavaScript
